# Burgundy Design System

Burgundy is a token-driven React design system focused on consistency, accessibility, and AI-readable UI rules.

## Architecture

```text
Primitive Tokens
      ↓
Semantic Tokens
      ↓
Style Dictionary
      ↓
CSS Variables
      ↓
Tailwind Theme
      ↓
React + CVA
      ↓
Storybook
      ↓
Product Patterns
```

## Design principles

### Tokens are the source of truth

Components consume semantic tokens rather than hard-coded visual values.

### Components own behavior

A component's contract includes its states, accessibility, interaction behavior, and variants—not just its appearance.

### Patterns compose primitives

Product-level patterns should reuse Burgundy components instead of recreating their behavior.

### Compliance is testable

Burgundy includes automated tests and an adherence checker to detect common violations.

### AI-ready UI

Burgundy includes explicit rules for AI-assisted UI generation.

The goal is not simply to generate something visually similar.

The generated implementation should remain inside the design system's contracts.
